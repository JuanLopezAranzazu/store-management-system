# Sistema de Gestión de Inventario

Aplicación web para la gestión de productos, categorías, usuarios e inventario.

El proyecto está dividido en un **frontend** desarrollado con React y un **backend** desarrollado con Fastify.

## Tecnologías

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui

### Backend

* Fastify
* TypeScript
* Prisma
* PostgreSQL
* Zod

## Inicio rápido

### Backend

```bash
cd backend
pnpm install
pnpm dev
```

### Frontend

```bash
cd frontend
pnpm install
pnpm dev
```

Para conocer la configuración, variables de entorno, comandos y estructura de cada parte del proyecto, consulta sus respectivos README:

* `backend/README.md`
* `frontend/README.md`
